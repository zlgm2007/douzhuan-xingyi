# 星野 · 太阳系行星页 —— 需求分析、技术方案与研发计划

> 基于「斗转 · 北斗七星」同一套渲染底座，另开一页：**以地球为视点，在夜空里显示太阳与七颗行星的真实位置**。
> 交付物：`prototype/index.html`（单文件、零构建、离线可跑，即原先的 `planets.html`） + 本文档。
> 目录约定：`index.html` = 星野行星页（站点首页），`beidou.html` = 斗转北斗原型（原 `index.html`）。

---

## 一、需求拆解

### 1.1 显性需求（用户原话）

| # | 需求 | 落地方式 |
|---|---|---|
| 1 | 「基于斗转，再分出一个页面」 | 新文件 `index.html`（原 `planets.html`），复用 `斗转`（现 `beidou.html`）的天空 / 星场 / 远山 / 水面 / 后处理整段模块，只换「天体层」与 HUD |
| 2 | 黑夜、以地球看星空 | 视点固定在半径 900 天球的球心（地面），所有天体都是**地心方向上的角位置**，不做太阳系 3D 沙盘 |
| 3 | 太阳 + 水金火木土天海（8 个） | 8 个天体全部计算，地球本身不出场（我们在上面） |
| 4 | 每个按颜色区分 | 每个天体独立色值：太阳暖白、水星灰褐、金星奶油黄、火星锈红、木星暖米、土星淡金、天王星青、海王星深蓝 |
| 5 | 太阳最亮 | 尺寸 + 光晕双维度最高权重（点径 26px + 3.6 倍光晕 + 十字衍射芒） |
| 6 | 土星带环 | 真正的 3D `RingGeometry`，法线沿土星北极（RA 40.589° / Dec 83.537°），开口角由几何自动得出 |

### 1.2 隐性需求（用户没说，但不做就不成立）

| # | 隐性需求 | 判断依据 | 处理 |
|---|---|---|---|
| A | **位置必须是真实星历**，不能是"画个大概" | 一旦是示意，这页就退化成贴图，失去"从地球看"的意义 | 采用 JPL 近似 Keplerian 根数，误差角分量级 |
| B | **必须能被地平/远山遮挡** | 斗转里刚踩过这个坑（星点穿山） | 复用同一套：星点高度角软淡出 + 山体深度遮挡 + 线段整段剔除 |
| C | **时间必须能推进** | 行星一晚上几乎不动，不能推进就永远看不到"升起/落下" | 拖拽 = 12 小时/屏宽，滚轮 = 1.6 小时/格，另有 4 档时间流速 |
| D | **必须能定位到具体某颗** | 天王星 5.8 等、海王星 7.8 等，肉眼在亮星堆里找不着 | 右侧（窄屏左下）清单 + 点击对准 + 屏幕标签 + 数字键 1~8 |
| E | **真实角径无法直视** | 木星最大约 50″，即 1/72 度；屏幕上不到 1px | 尺寸必须夸张，且要"夸张得讲道理"（按星等分级，不是乱给） |
| F | 为什么行星排成一条线 | 这是最有科普价值的现象 | 画一条低透明度黄道虚线，把"共面性"讲明白 |

### 1.3 明确不做（避免过度设计）

- 不做太阳系俯视沙盘 / 轨道椭圆 / 距离等比 —— 视角是"站在地球上抬头"，不是上帝视角。
- 不做月相、卫星（伽利略卫星、土卫六）、小行星带 —— 与"8 个主天体"的需求边界无关。
- 不做真实光害模型 / 天气 —— 默认理想观测条件。
- 不做行星表面贴图（木星条纹、火星极冠）—— 在 10px 的点径上无意义。

## 二、技术方案评估

### 2.1 三条可选路线

| 路线 | 做法 | 精度 | 成本 | 结论 |
|---|---|---|---|---|
| A. 手填角度 | 把"当前行星位置"写死成 RA/Dec | 一旦时间推进就错 | 0.5 天 | ❌ 只能做静态展示，与"能推时间"冲突 |
| B. 真实星历（JPL 近似根数） | 8 组轨道根数 + 开普勒方程 | 1800–2050 内约 **1′ 量级**；屏幕上远小于 1px | 1 天 | ✅ 采用 |
| C. 高精度星历（VSOP87 / DE440 查表） | 数百项级数或二进制历表 | 角秒级 | 3–5 天 + 数据文件 | ❌ 收益为零：像素尺度用不上 |

**决策：B**。理由：这页的精度上限由"1 像素 ≈ 4′"决定，B 已经远超需求；C 只是把算力花在看不见的地方。

### 2.2 坐标链（与斗转共用最后一环）

```
儒略世纪 T
  → 轨道根数 a,e,I,L,ϖ,Ω（含世纪变率）
  → 解开普勒方程 M = E − e·sinE（牛顿迭代 6 次）
  → 轨道平面直角坐标 → 日心黄道坐标（AU）
  → 减去地球日心矢量 = 地心黄道矢量（太阳则取 −地球）
  → 黄道 → 赤道（ε = 23.4392911°）
  → 复用斗转的 skyMatrix(lst)：赤道 → 地平（x 东 / y 天顶 / z 南）
```

关键点：**不重写地平变换**。`skyMatrix` 那三行如果符号写反，整片星空会镜像 —— 斗转已经踩过一次，这页直接沿用同一实现，风险归零。

恒星时改为由时间反算（`GMST = 280.46061837 + 360.98564736629·(JD−2451545) + …`，加观测地经度 113°E），这样"时间"是唯一真源，天体与星空永远同步。

### 2.3 渲染分层（复用 + 新增）

| 层 | 来源 | 说明 |
|---|---|---|
| 天空穹顶 + 银河 | 复用 | 程序化 `skyBase()` + 银道坐标 fbm 条带 |
| 5 万星场 | 复用 | 单 draw call 点精灵 |
| 远山 3 层 + 水面 | 复用 | 不透明网格写深度 → 天然遮挡行星 |
| **行星层（新）** | 新增 | 一个 `Points`，逐点属性 `aDir/aColor/aSize/aBoost/aMag` |
| **太阳（新）** | 同一 shader | `aBoost > 2` 分支走"超大核 + 强光晕 + 衍射芒" |
| **土星环（新）** | 新增 | `RingGeometry` + 自定义 band shader |
| **黄道线（新）** | 新增 | 180 段 `LineSegments`，地平以下整段剔除 |

行星层与斗转的 `brightStars` 是同一族写法：`transparent / depthWrite:false / depthTest:true / AdditiveBlending`，`renderOrder = 2`（晚于地形，深度测试负责被山挡住）。

### 2.4 尺寸与亮度模型（"夸张但要讲道理"）

- **尺寸**：真实角径算出来（`2·atan(D/2 / Δ)`，D 为行星直径 km），但只作为内部数据；显示点径用美术档位：太阳 26 > 木星 11 > 土星 10 > 金星 9 > 火星 7 > 水星 5.2 > 天王星 5.4 > 海王星 5.0（px）。
- **亮度**：星等由 `m = V0 + 5·lg(r·Δ)` 现算（V0 由各行星平均反照率标定），再映射为 alpha：`clamp(0.80 − 0.085·m, 0.32, 1.45)` —— 木星接近满值，海王星压到 0.32，**暗但不消失**（因为还要能被点中、能被标签指到）。
- **大气消光**：沿用斗转的 Kasten–Young 气团，贴地天体变暗并偏红（`mix(白, 暖橙, 1−ext)`）。
- **地平判据**：`smoothstep(0, 0.05, w.y) * smoothstep(-0.02, 0.02, w.y)`，与斗转同一套，保证"沉进地平雾"而不是硬切。

### 2.5 土星环：一个必须做取舍的物理细节

2025–2026 正是**土星环面穿越**周期，环几乎侧对地球 —— 真实几何下屏幕上就是一条 1px 的线，"带环"这个需求等于没实现。

处理：**保留真实极轴朝向，只在开口角小于 14° 时，把极轴绕 `(极轴×视线)` 旋转到最小 14°**。
于是：环的**方位角、椭圆长短轴方向**全部真实，只有"张开程度"被抬到可辨识下限。这是这个页面里唯一一处"为了让需求成立"的物理妥协，已在代码注释里写明。

### 2.6 日间与夜晚

这页的定位是"夜空观测"。太阳升到地平以上时不做真实天光（会把画面洗成白雾，实测失败），只保留：
- 极淡天光底噪（+0.011 线性亮度）；
- 星点压暗 55%（不归零，保留夜空观感）；
- HUD 提示「太阳在地平线以上 · 本页固定为夜空观测模式」。

默认时间 **落在夜里**：白天打开自动跳到当晚 21:30，避免一进来就是"黑天挂太阳"。

### 已修的关键问题（记录在案）

| 现象 | 根因 | 修法 |
|---|---|---|
| 白天整片白雾 | 天光叠加项过强 + Bloom 放大 | 从 +0.048 降到 +0.011，仅作"微亮" |
| 银河一片白光 | `uMilkyGain` 1.8 + 天空 0.95 乘子偏高 | 降到 1.15 / 0.80（水面 0.5→0.38），保留条带结构 |
| 拖拽一次跳 22 分钟（不稳） | 速度积分在事件批量到达时数值爆炸 | 改为直接映射：1 屏宽 = 12 小时 |
| 土星"看不见环" | 2026 环面穿越，真实几何 = 一条线 | 极轴最小张角 14°（见 2.5） |
| 窄屏清单压住行星 | 面板固定右上 | ≤860px 时移到左下并压缩为"名称 + 高度角" |

## 四、实测记录

- **星历一致性**：JS 结果与独立 Python（同一组 JPL 根数）逐项对齐，无偏差；2026-11-11 火星与木星确实在天球上靠得很近（RA 9.74h / 9.84h），不是 bug。
- **运行**：`http://127.0.0.1:8765/`（或 `index.html`），控制台零报错。
- **调试参数**：`?at=2026-11-11T22:40` 钉住观测时刻；无参数时白天自动落到当晚 21:30。
- **视口**：467×776 与 702×776 两种宽度均已检查版式。

## 五、后续可选项（按性价比排序）

1. **行星相位与亮度联动**：内行星加"月牙相位"遮罩（金星最戏剧性），成本约 0.5 天，观感收益大。
2. **时间轴条**：底部加一条可拖动的 24h 时间条 + 日出日落刻度，比"滚轮推时"更直观。
3. **行星合/冲提示**：角距 < 3° 时在两颗之间画一条细线并标注"合"，把"今晚值得看什么"讲出来。
4. **真实银河亮度分级**：按 Bortle 等级切换银河/星星可见度（乡村 vs 城市），一个滑块解决"银河到底该多亮"的争论。

> 关于"银河亮度"：它的正确锚点不是"好看"，而是**肉眼在无光害夜空里看到的那一层薄雾** —— 能看到条带与暗尘带，但绝不该亮到像云。当前参数按这个锚点定的：暗处能认出人马/天鹅方向的亮结，整体不抢行星的视觉优先级。
